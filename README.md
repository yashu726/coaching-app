# coaching-app

This is a full-stack coaching management application.

## 🚀 Features
- User Signup & Login
- Course Management
- Notes Upload (PDF)
- MCQ / PYQ Practice

## 🛠 Tech Stack
- Frontend: React + Tailwind + shadcn
- Backend: Node.js / .NET
- Database: SQL Server

## ▶️ Run Project

### Frontend
cd frontend
npm install
npm run dev
